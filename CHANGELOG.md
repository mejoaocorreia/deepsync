# Changelog

All notable public alpha changes are recorded here.

## 0.1.0-alpha.2 — 2026-08-26

- Hardened transaction binding, terminal-state atomicity, per-target heads, rollback recovery, artifact quarantine, and cross-process file locking.
- Replaced mutable DSH package input with complete packed-artifact validation and nonce-bound isolated target identity.
- Added verified committed-state LKG restoration, stable CLI exits, automatic recovery, exact Doctor runtime checks, bounded GitHub downloads, and offline packed-consumer gates.
- Added pinned DSH 0.1.1-rc.2 E2E evidence in Linux CI and matching local Windows coverage.

See the [Alpha.2 release notes](docs/release-notes-0.1.0-alpha.2.md) for compatibility and safety limits.

## 0.1.0-alpha.1 — 2026-08-24

- Published the initial target-neutral Core, isolated DSH adapter, lifecycle probe, CLI, Doctor, and release verification foundation.

See the [Alpha.1 release notes](docs/release-notes-0.1.0-alpha.1.md).
