# DeepSync

DeepSync is a target-neutral lifecycle platform for extensions of AI harnesses and agent runtimes. It manages discovery, compatibility evidence, planning, staging, activation observation, health, rollback, quarantine, and lock state. It is not a harness and does not execute extensions.

DeepSeek Harness is the first target. Alpha.1 is restricted to isolated, disposable, or explicitly stopped DSH profiles and never mutates an active Web profile.

Start with the [working quickstart](docs/quickstart.md). See [architecture](docs/architecture.md), [Alpha scope](docs/scope-alpha.md), the [compatibility matrix](docs/compatibility-matrix.md), and [Alpha.1 release notes](docs/release-notes-0.1.0-alpha.1.md).
